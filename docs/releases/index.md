# Releases

Release notes, one file per version, newest first. The
[changelog](changelog.md) is generated from `CHANGELOG.json` and lists every
change with its commit.

The latest release, [v0.2.0](v0.2.0.md), adds internal plans: a plan for the
operator's own accounts that is assigned by hand and never sold or shown.

The first, [v0.1.0](v0.1.0.md), is a machine-readable description of a
product's pricing and packaging, with validation, helpers for features and
limits, a pricing view, an entitlement map and a diff.
