# Releases

Release notes, one file per version, newest first. The
[changelog](changelog.md) is generated from `CHANGELOG.json` and lists every
change with its commit.

The latest release, [v0.1.0](v0.1.0.md), is the first: a machine-readable
description of a product's pricing and packaging, with validation, helpers for
features and limits, a pricing view, an entitlement map and a diff.
